# 🔍 MC Log Tool

一款专为 Minecraft 模组包玩家设计的**日志分析与模组管理工具**，帮助你快速定位游戏崩溃原因，管理模组依赖，支持超大日志文件（35 万+ 条）流畅分析。

---

## ✨ 功能特色

- **📂 导入日志**：支持导入单个 `.log` / `.txt` / `.zip` 文件，也支持导入整个文件夹（自动递归扫描）。
- **📊 分组归纳**：按日志级别（ERROR / WARN / INFO / DEBUG / EXCEPTION）自动分组，展开查看详情，支持分批加载（避免卡顿）。
- **🧩 模组管理**：自动扫描 `.minecraft` 目录下的模组列表，支持多目录累加、去重，并持久化保存。
- **🔍 智能分析**：综合日志错误和模组列表，智能分析可能崩溃原因，给出解决建议（内存不足、模组缺失、Java 版本等）。
- **🎨 自定义外观**：支持深色/浅色模式，可设置背景图片（包括 GIF 动图）。
- **⚙️ 灵活设置**：自定义每页显示条数、分组最大显示条数，性能优化选项。
- **💾 数据持久化**：设置、展开状态、模组库等信息保存在本地，重启后自动恢复。
- **⚡ 高性能**：采用 IndexedDB 本地存储 + 分批写入，支持 35 万+ 日志流畅导入与分页。

## 🖥️ 使用说明
- ** 导入日志 **：点击“导入日志”或“导入文件夹”，选择你的 Minecraft 日志文件（或包含日志的文件夹）。
- ** 分组归纳 **: 在“分组归纳”页面，点击任意级别展开查看具体错误信息。
- ** 模组管理 **: 在“模组管理”页面，点击“选择 .minecraft 目录并扫描”，程序会自动识别并添加模组列表。
- ** 分析报错 **: 点击侧边栏“分析报错”，工具将综合日志和模组列表，给出可能的崩溃原因及解决方案。
- ** 个性化设置 **: 在“设置”页面，调整显示条数、主题（深色/浅色）、背景图片等。
